Build a research agent that finds a tool, researches the latest TypeScript release, and returns a summary with sources and tool cost.

<Accordion title="Add to an existing agent">
  Import the helper and add it to your agent's `tools`:

  ```typescript
  import { agentmuxer } from "@agentmuxer/sdk/openai";
  import { Agent } from "@openai/agents";

  const agent = new Agent({
    name: "Research assistant",
    tools: [agentmuxer()],
  });
  ```
</Accordion>

## Before you start

- Node.js 22.18 or later with ESM; see [compatibility](/reference/compatibility).
- An [AgentMuxer application key](/sdk/applications) and credits for paid calls.
- An OpenAI API key for the model.

<Note>
  This example requests one purchase up to \$0.10; model charges are separate. A prompt budget guides the agent. An [application spending limit](/sdk/applications) enforces a cumulative cap.

  Before running unattended, [configure payment confirmation](/guides/billing#unattended-applications). This example cannot collect human payment confirmation. The setting is account-wide and also affects personal agents; the SDK never changes it.
</Note>

<Steps>
  <Step title="Install">
    In a new directory, create an ESM project and install the integration:

    ```bash
    mkdir my-agent
    cd my-agent
    npm init -y
    npm pkg set type=module
    npm install @agentmuxer/sdk @openai/agents
    ```
  </Step>
  <Step title="Set your keys">
    Export these in the terminal where you will run the agent:

    ```bash
    export AGENTMUXER_API_KEY='your-application-key'
    export OPENAI_API_KEY='your-model-provider-key'
    ```

    AgentMuxer authenticates with the application key; no OAuth login is required. Keep keys on your server and out of source control.
  </Step>
  <Step title="Create your agent">
    Save this as `agent.ts`:

    ```typescript agent.ts
    import { agentmuxer } from "@agentmuxer/sdk/openai";
    import { Agent, run } from "@openai/agents";

    const prompt = process.argv[2] ?? `Use AgentMuxer to research the latest TypeScript release.
    Summarize three changes with sources.
    You may buy one tool call up to $0.10 (maxCostMicros: "100000").
    Do not accept higher-priced terms.
    Report the actual tool cost or explain any refusal.`;

    const agent = new Agent({
      name: "Research assistant",
      tools: [agentmuxer()],
    });
    const result = await run(agent, prompt);
    console.log(result.finalOutput);
    ```
  </Step>
  <Step title="Run">
    ```bash
    node agent.ts
    ```

    The example asks the agent to print:

    - Three TypeScript release changes.
    - Sources for the summary.
    - The actual tool cost, or the reason it could not complete the purchase.

    To supply your own task, run `node agent.ts 'your task and purchase budget'`. Include the maximum number of purchases and price you authorize.
  </Step>
</Steps>

## Customize permissions

`agentmuxer()` exposes all AgentMuxer tools, including purchases. OpenAI tool approval defaults to `requireApproval: "never"`; AgentMuxer's spending and payment-confirmation controls still apply.

Pass `allowedTools` to filter exposed tools. For OpenAI approval prompts, pass `requireApproval: "always"` and implement [approval interruptions and resumption](https://openai.github.io/openai-agents-js/guides/human-in-the-loop/).

OpenAI receives the application key and connects to AgentMuxer on your behalf. See the [SDK reference](/reference/sdk) for all options.
