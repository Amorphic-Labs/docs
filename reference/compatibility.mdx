This page describes `@agentmuxer/sdk` 0.6.x.

## Runtime support

| Environment | Support |
| --- | --- |
| Node.js 22.18+ with ESM (`import`) | Supported for every entry; tested on Node 22 and 24 |
| Node.js 22.18+ with CommonJS (`require()`) | Supported for `@agentmuxer/sdk`, `@agentmuxer/sdk/contracts`, and `@agentmuxer/sdk/admin` |
| Framework adapters (`/openai`, `/claude-agent`, `/ai-sdk`) | Load with `import` from ESM |
| Browser or mobile bundle | Keep application keys on your server; the SDK refuses to use a key in a browser |
| Bun, Deno, Cloudflare Workers, and other edge runtimes | Not supported yet; support is planned |

```js
const { AgentMuxer } = require("@agentmuxer/sdk");
const { AgentMuxerAdmin } = require("@agentmuxer/sdk/admin");
```

TypeScript projects that compile to CommonJS need TypeScript 5.8 or later with `"module": "nodenext"`. The `@agentmuxer/cli` command also runs on Node.js 22.18 or later.

For Claude Agent SDK, also check its [hosting requirements](https://code.claude.com/docs/en/agent-sdk/hosting).

## Framework dependencies

The direct client (`new AgentMuxer()`) and the Admin client (`new AgentMuxerAdmin()`) need no framework packages. For a framework adapter, install only the dependencies for your integration. The package declares these optional peer ranges:

| Import | Framework dependency |
| --- | --- |
| `@agentmuxer/sdk/openai` | `@openai/agents ^0.18.0` |
| `@agentmuxer/sdk/claude-agent` | `@anthropic-ai/claude-agent-sdk ^0.3.273` |
| `@agentmuxer/sdk/ai-sdk` | `ai ^7.0.102` and `@modelcontextprotocol/client ^2.0.0` |

Each release is tested against these ranges. Each integration guide includes all packages needed to run its example.

## Approvals and connection behavior

| Integration | Connection | What your application handles |
| --- | --- | --- |
| Direct client | HTTPS requests to the AgentMuxer API | `run` results, including `requires_action` and refusals, and recovery by idempotency key |
| OpenAI Agents | OpenAI's hosted MCP connection | OpenAI approval interruptions if you opt into `requireApproval: "always"` |
| Claude Agent SDK | HTTP MCP server in the Claude runtime | Native tool permission configuration |
| Vercel AI SDK | MCP client created by the helper | Result/stream consumption and `close()`; purchase confirmation with `confirmation: "manual"` |

Framework approval is separate from AgentMuxer's payment confirmation. When an application requires a person to confirm purchases, the Vercel AI SDK helper with `confirmation: "manual"` pauses the purchase and resumes it on a later authenticated request. See the [SDK README](https://www.npmjs.com/package/@agentmuxer/sdk) for the flow.

See [billing and approvals](/guides/billing) for unattended runs. The SDK never changes your account's confirmation setting.

## Other integrations

[Native MCP recipes](/sdk/native-mcp) cover frameworks and hosted connectors that accept remote MCP configuration. These are separate from the three SDK adapters above. Follow each client's requirements for authentication, approvals, and connection cleanup.

For personal-agent setup, use [Connect your agent](/guides/connect).

## Upgrading

<Steps>
  <Step title="Read the changelog">
    Review [release notes](/changelog) before upgrading, especially between minor versions during `0.x`.
  </Step>
  <Step title="Check your dependencies">
    Confirm that your runtime and framework versions satisfy the new package's requirements.
  </Step>
  <Step title="Run your integration">
    Verify authentication, tool execution, approval behavior, and cleanup in your application's environment before rollout.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="From 0.5 to 0.6">
    The client is a class. Replace `createClient()` with `new AgentMuxer()` from `@agentmuxer/sdk`, and `createAdminClient()` with `new AgentMuxerAdmin()` from `@agentmuxer/sdk/admin`. Methods take `(input, options?)`, so pass an abort signal as `{ signal }`. Add a `default` branch to exhaustive `switch` statements over refusal reasons, and rename the adapters' `AgentMuxerOptions` types to `OpenAIAgentsOptions`, `ClaudeAgentOptions`, and `AISDKOptions`. Follow **Upgrading from 0.5** in the [SDK README](https://www.npmjs.com/package/@agentmuxer/sdk) for the full table.
  </Accordion>
  <Accordion title="From 0.2.0 or earlier with the Vercel AI SDK">
    Since 0.2.1, the Vercel AI SDK adapter uses the `ai` and `@modelcontextprotocol/client` packages. Replace `@ai-sdk/mcp` with them in your dependencies:

    ```sh
    npm uninstall @ai-sdk/mcp
    npm install @agentmuxer/sdk@latest ai @modelcontextprotocol/client
    ```

    Transport errors use the MCP client's error classes, and each tool call allows 100 seconds.
  </Accordion>
  <Accordion title="From 0.2.x with the agentmuxer command">
    The `agentmuxer` command moved to `@agentmuxer/cli` in 0.3.0. Run `npm uninstall -g @agentmuxer/sdk` before installing the CLI globally.
  </Accordion>
</AccordionGroup>

During `0.x`, minor releases may include breaking changes or new features. Patch releases contain backward-compatible fixes. SDK versions are independent of MCP protocol versions.
