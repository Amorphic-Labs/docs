For Codex, Claude Code, OpenCode, and other coding agents, paste this line into your agent:

```text
Set up AgentMuxer from https://agentmuxer.com/SKILL.md
```

<Steps>
  <Step title="Install">
    Your agent runs the AgentMuxer installer. It connects every supported coding agent on your machine to AgentMuxer and adds guidance to call a known API directly or search the free catalog when a task needs external tools or information.

    To run setup yourself in a terminal with Node.js 22.18 or later and npm:

    ```sh
    npx -y @agentmuxer/cli@latest install
    ```

    To set up only some clients, add `--client codex`, `--client claude-code`, or `--client opencode`. Repeat the flag to choose several.
  </Step>
  <Step title="Sign in">
    Sign-in is required for free and paid use. Each client signs in to AgentMuxer with OAuth in your browser and keeps its own sign-in.

    - **When your agent runs setup,** it relays each step for you as an `Owner action:` line. Follow them in order. They include approving sign-in and, depending on the client, one command that continues the same conversation: `/reload-plugins` in Claude Code, `codex resume` in Codex, or `opencode -c` in OpenCode.
    - **When you run setup in a terminal,** it signs in the AgentMuxer CLI, then opens each signed-out client's browser sign-in, one at a time.

    Existing settings and sign-ins are preserved, and running `install` again updates AgentMuxer's guidance in place.
  </Step>
  <Step title="Try it">
    After the sign-in steps, paste this prompt. After a terminal setup, start your coding agent and paste it there. For connector clients, start a new conversation.

    ```text
    Use AgentMuxer to find tools that could help with this project. Recommend one, explain what it does and its price, and don't execute a paid call.
    ```

    This first prompt explores the catalog without buying a tool call. Next, [give your agent a task](/guides/use-tools).
  </Step>
</Steps>

## Use AgentMuxer from a terminal

The `agentmuxer` command searches, inspects, and calls APIs from a terminal or script. Install it globally and sign in:

```sh
npm install -g @agentmuxer/cli
agentmuxer login
agentmuxer search --query "web search API"
```

`agentmuxer login --no-browser` prints the sign-in URL and code instead of opening a browser. Without a global install, prefix commands with `npx -y @agentmuxer/cli@latest`. See the [CLI README](https://www.npmjs.com/package/@agentmuxer/cli) for every command.

## Other clients and manual setup

The installer also adds reusable guidance. Manual MCP registration adds the connection only. Every client below starts the OAuth sign-in when it first connects.

<Tabs>
  <Tab title="claude.ai or ChatGPT">
    In your platform's connector settings, add a custom connector with this URL, then complete sign-in:

    ```text
    https://mcp.agentmuxer.com/mcp
    ```

    Start a new conversation after connecting. Custom connector availability depends on your platform and plan.
  </Tab>
  <Tab title="Codex">
    Run both commands; the second opens browser sign-in. Then restart open Codex sessions.

    ```sh
    codex mcp add agentmuxer --url https://mcp.agentmuxer.com/mcp
    codex mcp login agentmuxer
    ```
  </Tab>
  <Tab title="Claude Code">
    Run both commands; the second opens browser sign-in. Then restart open Claude Code sessions.

    ```sh
    claude mcp add agentmuxer --transport http https://mcp.agentmuxer.com/mcp
    claude mcp login agentmuxer
    ```
  </Tab>
  <Tab title="Cursor">
    Add this to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (one project), preserving any existing servers. Complete sign-in when Cursor connects.

    ```json
    {
      "mcpServers": {
        "agentmuxer": { "url": "https://mcp.agentmuxer.com/mcp" }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Add this to `.vscode/mcp.json`, preserving any existing servers. Complete sign-in when VS Code connects.

    ```json
    {
      "servers": {
        "agentmuxer": {
          "type": "http",
          "url": "https://mcp.agentmuxer.com/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Gemini CLI">
    Add the server, then run `/mcp auth agentmuxer` in Gemini CLI to sign in:

    ```sh
    gemini mcp add -s user --transport http agentmuxer https://mcp.agentmuxer.com/mcp
    ```
  </Tab>
</Tabs>

[SKILL.md](https://agentmuxer.com/SKILL.md) has setup steps for more agents, and [setup.md](https://agentmuxer.com/setup.md) collects the manual recipes.

## Manage the connection

<AccordionGroup>
  <Accordion title="Check setup or reconnect">
    Run the status command:

    ```sh
    npx -y @agentmuxer/cli@latest status
    ```

    It prints one line per client and the CLI sign-in. Follow any `Owner action:` line it prints to finish setup or sign in again. For client errors or interrupted sign-in, see [troubleshooting](/reference/troubleshooting).
  </Accordion>
  <Accordion title="Remove the installer-managed connection">
    ```sh
    npx -y @agentmuxer/cli@latest remove
    ```

    This removes the installer-managed guidance and removes or disables its connection. Restart open clients afterward. For a manually added connector, remove it in the client's settings.
  </Accordion>
  <Accordion title="Moving from @agentmuxer/setup">
    `@agentmuxer/cli` replaces `@agentmuxer/setup`. Run `npx -y @agentmuxer/cli@latest install` to update your clients and guidance.
  </Accordion>
</AccordionGroup>

<Info>
  Building and distributing your own agent? Use an [application API key](/sdk/applications) with the SDK. That flow does not require browser sign-in for each run.
</Info>
