The TypeScript SDK connects your existing agent to AgentMuxer. It exposes tools for discovery, inspection, purchases, and outcome reporting.

## Before you start

<Steps>
  <Step title="Use a supported runtime">
    Use Node.js 22.18 or later with ESM. See [compatibility](/reference/compatibility) for the tested runtimes and framework versions.
  </Step>
  <Step title="Create an application key">
    Open [Applications](https://app.agentmuxer.com/dashboard/applications), create an application, and save its key as `AGENTMUXER_API_KEY` on your server. Application keys authenticate without an OAuth sign-in.
  </Step>
  <Step title="Prepare for the example purchase">
    Add credits in your [dashboard](https://app.agentmuxer.com/dashboard). The quickstarts ask the agent to buy one tool call up to \$0.10. Your model provider bills separately.
  </Step>
</Steps>

<Note>
  A prompt's budget guides the agent. Set an optional application spending cap in the dashboard when you need a server-enforced cumulative limit. Applications default to no limit. See [billing and approvals](/guides/billing) before running unattended agents.
</Note>

## Already using another framework?

Use the [native MCP connection](/sdk/native-mcp) if your framework accepts a remote MCP server. You do not need to replace your agent framework or install an AgentMuxer helper for every client.

## What happens next?

Your agent searches for a relevant capability, inspects it, and calls it if the task and spending controls allow. The example prints the agent's answer; ask it to include sources and actual tool cost. If a purchase is blocked, follow the returned next action rather than repeatedly running the example.
